Ferramentas MCP

Plugue servidores MCP (busca web, arquivos, GitHub...) e a Lumi ganha as ferramentas automaticamente.

Formato (nome → comando). No Windows, use cmd /c npx pra rodar pacotes npx:

{ "filesystem": { "command": "cmd", "args": ["/c", "npx", "-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\thoma\\Desktop"] } }

Procure servidores em github.com/modelcontextprotocol/servers. As ferramentas MCP pedem permissão (aba Acesso → "Ferramentas MCP").
